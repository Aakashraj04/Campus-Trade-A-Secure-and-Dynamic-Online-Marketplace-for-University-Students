# Campus Trade – Student Marketplace Web Application

A web-based marketplace that enables students to securely buy, sell, and exchange items within their campus community.

---

## About

Campus Trade is a student-focused marketplace designed to simplify peer-to-peer trading within a university. The platform provides a secure environment where users can list items, browse products, and communicate with other students.

It eliminates the need for unstructured social media trading by offering a verified system with authentication, structured data handling, and organized listings.

---

## Features

- Secure user authentication using Firebase Authentication  
- Post, browse, search, and filter product listings  
- Image upload and storage using Firebase  
- Real-time data handling for listings and user interactions  
- Simple and intuitive user interface for seamless trading  

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend/Data Handling:** Firebase (Authentication, Database, Storage)  
- **Image Storage:** Cloudinary / Firebase Storage  
- **Tools:** Git, GitHub, VS Code  

---

## How It Works

1. Users sign up and log in using secure authentication  
2. Sellers post items with images and details  
3. Buyers browse, search, and filter listings  
4. Users interact through the platform for item exchange  
5. Data is stored and managed using Firebase services

## Key Challenges Solved

- Managing structured data for users and product listings  
- Ensuring secure authentication and controlled access  
- Handling real-time updates and user interactions  
- Maintaining data consistency across multiple users  

---

## Results and Impact

Campus Trade provides a secure and efficient platform for student-to-student trading.  
It improves accessibility to affordable items, promotes reuse of goods, and enhances campus connectivity through a structured digital marketplace.
